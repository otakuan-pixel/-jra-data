# 2段目のモデル（第4版SIMの上に載せる勝率モデル）の検証

対象エンジン：`otakuan-pixel/jra2` の `tools/keiba_sim.py`（第4版・2026-11-17）
データ：同リポジトリの `data/results`（2021-01〜2026-11-15、277,683走）
検証日：2026-11-18

## 結論

1. **オッズ込みの勝率は、市場（確定オッズ）より確かに良くなった。**
   第4版の期待値機能（MK）の11項目に4項目を足した15項目のモデルで、2025〜26年の5,728レースの対数損失が市場の1.9338から1.9293に下がった。
   学習はテスト対象の四半期より前のデータだけで行い、足す4項目も2024年だけで選んだ（2025〜26年は選ぶのに使っていない）。
   レース単位のブートストラップでは、改善幅0.0045（95%の幅は0.0017〜0.0071）、市場より良い確率は99.9%。
2. **ただし、単勝で儲かることは示せていない。**
   - 期待値1.0以上・50倍未満：572点、回収率97%（95%の幅72〜123%）
   - 期待値0.9以上・50倍未満：4,737点、回収率89%（95%の幅80〜98%）。100%を超える見込みはほぼ無い
   - これらは確定オッズで計算した値で、発走前のオッズで買う実戦ではさらに下がる（前日オッズで87%まで落ちることを第4版で確認済み）
3. **オッズなしのSIM（能力値だけ）は、2段目を足しても少ししか伸びない。**
   第4版：対数損失2.0453、◎の勝率30.2%
   2段目（62項目を同時に学習）：2.0388、30.6%
   市場との差（約0.11）はほとんど縮まらない。
4. **第4版のMKの成績は、少し良く見えていた。**
   係数を推定した期間と同じ2025〜26年で採点していたので、対数損失は1.9284と出ていた。
   同じ11項目を「それより前のデータだけ」で推定し直すと1.9305になる。市場よりは良いが、差は半分ほどになる。

## 試したもの（2025〜26年・5,728レース。すべてテストより前のデータだけで学習）

| モデル | 対数損失 | ◎の勝率 | ◎の3着内 |
|---|---|---|---|
| 市場（確定オッズ） | 1.9338 | 33.3% | 65.2% |
| 第4版SIM（オッズなし） | 2.0453 | 30.2% | 61.8% |
| 2段目・オッズなし（62項目） | 2.0388 | 30.6% | 62.5% |
| LightGBM・オッズなし | 2.0826 | 30.3% | 62.8% |
| 2段目・オッズあり（62項目を同時に学習） | 1.9381 | 33.4% | 65.5% |
| LightGBM・オッズあり | 1.9852 | 32.5% | 65.2% |
| 2段目の勝率と市場を2係数で合成 | 1.9332 | 33.5% | 65.4% |
| 第4版MK 11項目（同期間で推定済み・参考） | 1.9284 | 33.6% | 65.6% |
| 第4版MK 11項目（前のデータだけで再推定） | 1.9305 | 33.6% | 65.4% |
| **選んだ15項目（MK＋4項目）** | **1.9293** | 33.3% | 65.5% |

分かったこと：

- 項目を多く入れるほど、オッズありのモデルは悪くなる（学習しすぎ）。市場がすでに大半の情報を織り込んでいるので、足せるのは市場が見誤る向きだけで、効く項目は少ない。
- オッズありのモデルを2着・3着の並びまで使って学習すると悪くなる（11項目で1.9305から1.9375へ）。単勝のオッズなので、1着だけで学習する。
- LightGBMはこのデータ量では条件付きロジット（レース内で勝率を割り振るロジスティック回帰）に負ける。
- 新しく作った特徴のうち、ブリンカー、馬体重の増減、乗り替わり、馬主の成績は選ばれなかった。生産者の「オッズより勝つ度合い」だけが効いた。

## 選んだ15項目と係数（`coef_final.json`、2023-01〜2026-11-15の全レースで推定）

勝率 = レース内で softmax（Σ 係数 × 特徴）

| 項目 | 係数 | 読み方 |
|---|---|---|
| log_pm（市場の勝率の対数） | +0.999 | 土台は市場 |
| mu（第4版の能力値） | +0.362 | 能力値の高い馬は市場の見立てより少し勝つ |
| c_rec（通算3着内率の補正） | −1.126 | 第4版が足した分を打ち消す以上に引く＝成績の良い馬は市場で買われすぎ |
| c_last（前走着順の補正） | −1.267 | 同上。前走で好走した馬は買われすぎ |
| c_draw（コースごとの枠の有利不利） | +0.548 | 枠の有利不利を市場は織り込みきっていない |
| brd_vm（生産者がオッズより勝っている度合い） | +0.221 | 新しい項目。生産者の傾向は続く |
| k_drop（前走より下のクラス） | −0.207 | 買われすぎ（第4版と同じ向き） |
| k_jk_wr（騎手の勝率） | −0.119 | 上位騎手は買われすぎ（同） |
| k_closer / k_n1 / k_quick | −0.09 / −0.06 / −0.03 | 追込、過去走1走、連闘・中1週は買われすぎ（同） |
| k_l10 / k_a3 | +0.07 / +0.05 | 前走10着以下、古馬と走る3歳は低く見られがち（同） |

## 再現のしかた

```bash
git clone https://github.com/otakuan-pixel/jra2.git jra2            # --depth を付けない
cp jra2/tools/keiba_sim.py keiba_sim_v4.py
python3 -I keiba_sim_v4.py builddb --repo jra2 --out db             # 約30秒
python3 features.py --db db --engine keiba_sim_v4.py --since 20230101 --procs 4 --out feats.csv.gz   # 4コアで約35分
python3 stage2.py --feats feats.csv.gz --test-from 20250101 --oos-from 20240101 [--gbm]           # 表の上半分
python3 exp_mk.py         # MK 11項目の再推定、正則化の比較
python3 exp_select.py     # 2024年で項目を選び、2025〜26年で採点 → selected.json, p_sel.npy
python3 exp_boot.py       # ブートストラップ（誤差の幅）
python3 fit_final.py      # 全期間で最終の係数 → coef_final.json
```

`features.py` は第4版の `rate()` をそのまま写し、各補正の加算量を記録するようにしたもの。356頭で第4版と能力値が一致することを確かめた（差は1e-15）。
依存：numpy, pandas, scipy（LightGBMを試すときは lightgbm と scikit-learn）。

## 本番（`sim --odds`）へ入れるには

`keiba_sim.py` の `market_ev()` を、MKの11項目から `coef_final.json` の15項目に差し替える。追加で要るのは次の4つ。

- `c_rec`、`c_last`、`c_draw`：`rate()` の中で計算済みの補正の加算量を返り値に足すだけ
- `brd_vm`：出馬表に生産者の欄があるかを確認し、無ければ成績データの過去走から馬名で引く

★☆の基準と「検証中」の断り書きは変えないほうがよい。確率の精度は上がったが、回収率100%超えは誤差の範囲で、示せていない。

# 第5版：指数の見直し（2026-11-18）

エンジンの変更は `otakuan-pixel/jra2` のブランチ `claude/v5-figures`（`tools/keiba_sim.py`、`tools/README.md`）。

## 何をしたか

1. **`figlab.py` で指数の作り方を比べた。**
   2024年の全レース（約3,000）について、毎週「その週より前のデータだけ」でモデルを作り、約40通りの設定で次の2つを測った。2025〜26年は使っていない。
   - 指数だけの当たり具合（`mu_only`）
   - 市場に足せる情報の量（`市場比`）
2. **わかったこと：時計を重く見ると、2つの指標が逆を向く。**
   時計の反映（w_resid）を上げると、指数だけの当たり具合は悪くなる（0.3で2.0110 → 1.0で2.0345）。一方で、市場に足せる情報は増える（+0.0011 → +0.0024）。市場は相手関係の評価をよく織り込んでいるが、時計は織り込みきっていない。
3. **そこで指数を2本にした。**
   - SIM用の指数：時計0.5、スローの割り戻し0.7、レースレベルの寄せ方2、過去走の人気0.4、少ない出走数の寄せ方0.15。どれも単独で少し良くなった値
   - 時計重視の指数 mu_t：時計1.0、過去走の人気なし。オッズ込みの期待値でだけ使う
   2本を両方使うと、市場に足せる情報は+0.0043になった（第4版の指数だけなら+0.0011）。
4. **オッズ込みの期待値（MK）を16項目にした。**
   前回選んだ15項目（2024年で選んだもの）に mu_t を足した。

## 結果（2025〜26年・5,728レース。オッズ込みは四半期ごとに、それより前のデータだけで学習）

| | 対数損失 | ◎の勝率 | ◎の3着内 |
|---|---|---|---|
| 市場（確定オッズ） | 1.9338 | 33.3% | 65.2% |
| SIM 第4版 | 2.0453 | 30.2% | 61.8% |
| SIM 第5版 | 2.0429 | 30.2% | 61.9% |
| MK15・第4版の指数 | 1.9293 | 33.3% | 65.5% |
| **MK16・第5版（＋mu_t）** | **1.9275** | 33.5% | 65.1% |

改善の大きさ（ブートストラップ）：

- 第5版のMK16と市場の差：+0.0063（95%の幅 +0.0030〜+0.0096）
- 第5版のMK16と第4版のMK15の差：+0.0018（同 +0.0001〜+0.0034）
- SIM単独の第5版と第4版の差：+0.0025（同 −0.0015〜+0.0067。はっきりしない）

単勝の回収率（確定オッズ・MK16）：

- 期待値0.9以上・50倍未満：92%（84〜100%）
- 期待値1.0以上・50倍未満：94%（76〜113%）
- 期待値1.1以上・50倍未満：148%（95〜208%）。207点だけで、区切りも後から見つけたもの

エンジンの `validate`（2025-01〜2026-11-15、同じ期間で第4版と比べた）：

- SIMの◎：30.2%・61.9%・対数損失2.044（第4版は30.2%・61.8%・2.046）
- 5頭推奨（オッズ＋SIM）：どちらも36.7%
- 想定時計：第5版は平均+0.071秒/1000mずれたので、TIME_BIASを1.36→1.29に直した

## 効かなかったもの

| 試したこと | 結果 |
|---|---|
| 最近の走りをもっと重く見る（recency 90〜120日） | 悪化 |
| 大敗の着差を縮める・着差の上限を変える | 悪化 |
| 芝ダが違う走りを軽く見る | 悪化 |
| 年齢による成長の補正 | 2〜3歳でも、次走の指数は平均でほぼ上がっていない |
| ブリンカー、馬体重の増減、乗り替わり、馬主 | 2段目で選ばれなかった |
